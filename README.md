# Foxcraft

A fan-made, early-alpha-style voxel sandbox starring a fox. Mine, build, and explore a procedurally generated world with gritty pixel textures, heavy fog, and blocky clouds, right in your browser.

## Features

- Procedural terrain with hills, lakes, caves, ores, and trees
- Fox player with walking, swimming, and mining animations, in first or third person
- Mine and place blocks, with a 9-slot hotbar
- Fog modes, seed picker, and an F3 debug screen
- Procedural sound effects (Web Audio)
- Every texture, skin, and sound is generated at runtime, so there are no external assets
- Touch controls for mobile

## Controls

| Input | Action |
| --- | --- |
| W A S D / Arrow keys | Move |
| Space | Jump / swim up |
| Shift | Sprint |
| Left click | Mine |
| Right click | Place block |
| 1-9 / Mouse wheel | Select hotbar slot |
| F | Cycle fog |
| V / F5 | Toggle camera |
| G / F3 | Debug info |
| M | Toggle sound |
| Esc | Pause |

## Built with

Next.js, React, Three.js, and Tailwind CSS.

## Notes

Worlds are not saved. This is an unofficial fan project and is not affiliated with any company.
